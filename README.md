# 🧾 Project Overview

This project is part of the CodeAlpha Data Analytics Internship. This project presents an interactive **Sales Analysis Dashboard** created using **Tableau**.  
The dashboard helps analyze:

- 📈 Total Sales & Profit
- 🌍 Region-wise Performance
- 🛒 Segment-wise Sales
- 🚚 Shipping Mode Analysis
- 🗺️ State-wise Sales Distribution
- 📦 Product Category Performance

The dashboard provides meaningful business insights that help organizations improve profitability and sales performance.

# 📊 Dashboard Features

---

## ✅ Segment Wise Sales & Profit

Analyze performance of:

- Consumer
- Corporate
- Home Office

Sub-categories include:

- Phones
- Chairs
- Tables
- Binders
- Storage

---

## ✅ Region Wise Sales Analysis

Regions Covered:

- West
- East
- Central
- South

Insights:
- West region contributes highest sales.
- South region shows lowest performance.

---

## ✅ Shipping Mode Analysis

Order Modes:

- 🚚 Standard Class
- ⚡ First Class
- 🚀 Second Class
- 🕒 Same Day

Insights:
- Standard Class has maximum orders.
- Same Day shipping has minimum usage.

---

## ✅ State Wise Sales Map

Interactive map visualization showing sales distribution across U.S. states.

Key Insight:
- California has highest sales contribution.

---

# 📌 Key Business Insights

✔️ Consumer segment generates highest sales and profits.  
✔️ Phones and Chairs are most profitable products.  
✔️ Tables category has lower profit margins.  
✔️ West region performs best in sales.  
✔️ South region requires improvement strategy.  
✔️ Standard Class shipping is most preferred by customers.
